# Datasets

Documentation about datasets used by this project (schemas, provenance,
known issues) goes here — not the datasets themselves. See
`data/README.md` for the data directory layout and Git-tracking rules.

- [`io_vnbd.md`](io_vnbd.md) — IO-VNBD: provenance, acquisition procedure
  (the repo copy is Git LFS pointers, not data), structure, and the measured
  findings that constrain how it may be used.

The full measured analysis is regenerated by
`python -m idr.dataset.inspect` into `data/metadata/io_vnbd/` and
`reports/io_vnbd/`.
